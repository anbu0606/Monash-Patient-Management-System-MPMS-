# Project info
## Name
Monash Patient Management System (MPMS)
## Description
MPMS is an application to manage a healthcare system in which there are two user roles -- Patient & Admin. MPMS allows for creation of AppointmentSlots, Booking Appointments, viewing user profiles, etc. to provide a system for complete management of many clinics at once.
MPMS allows for different functions for different roles.

## Installation
MPMS exclusively utilises the Python Standard library.
Python3.11+ is  recommended.

## Usage
To start mpms, navigate to "Project" folder and NOT "src".
In the terminal, enter: python.exe ./src/mpms.py
